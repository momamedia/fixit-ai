🔁 Lead Router path fails

1. Visitor calls tracking number
e.g. (213) 652-7656 or DNI unique number
t=0
2. Lead Router receives the call
SignalWire → campaign routing engine
t ≈ 0–1s
3. Lead Router pings buyers (RTB auction)
Proaxis, Lead Smart asked for a bid
auction runs (~1s)
4. A buyer bids → reservation minted
e.g. Lead Smart wins, $38.70
bid is valid ~13s
5. Call must route within ~13 seconds
If routing finishes after the reservation expires → RTB_LATE_PING_LR-103
window ~13s ⚠️
6. Call hangs up — not connected
No buyer destination reached in time
FAIL
Root cause: The Lead Router's internal RTB reservation/window is ~13s, and it is not adjustable from the account/platform API we can access.

⚡ Proaxis direct bridge connects

1. Visitor completes chat (qualified)
Name + ZIP + phone collected
t=0
2. Our server pings Proaxis directly
Not through the Lead Router auction
~1s
3. Proaxis returns a bridge number
e.g. +1 424-509-1346, bid $27.44
reservation ~240s (4 min)
4. Chat shows "Call now" with the bridge number
Visitor has plenty of time to dial
window 240s ✅
5. Visitor calls the bridge number
Connected directly to the Proaxis buyer
CONNECTED
Why it works: Proaxis holds its reservation for 240 seconds, so the visitor can comfortably call before it expires — no 13s race.
